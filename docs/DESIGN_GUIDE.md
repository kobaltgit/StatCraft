# StatCraft Canonical Dialog Design Guide (DialogKit Standard)
# Стандарт экосистемы ArtCraft / storytold

Данный документ устанавливает официальный визуальный и архитектурный канон построения диалоговых окон в приложении **StatCraft** на базе классического эталона IBM SPSS Statistics с учётом эргономики современных десктопных интерфейсов.

---

## 1. Архитектурные архетипы диалоговых окон

В StatCraft все диалоговые окна делятся на 4 строгих архетипа:

| Архетип | Назначение | Базовый размер ($W \times H$) | Компоновка |
| :--- | :--- | :--- | :--- |
| **Type 1: Statistical Procedure** | Запуск статистических процедур (Frequencies, Descriptives, T-Tests, ANOVA) | **$560 \times 430\text{ px}$** | 3 колонки: список доступных переменных $\to$ кнопка переноса $\to$ целевой список + правая колонка вызова поддиалогов + нижний Action Bar |
| **Type 2: Subdialog / Options** | Модальные параметры процедур (Options, Statistics, Define Groups) | **$360 \times 300\text{ px}$** | Модальное окно поверх родительского: сгруппированные чекбоксы/поля (GroupBox) + нижний ряд `[ Continue ] [ Cancel ] [ Help ]` |
| **Type 3: Variable Properties** | Редактирование метаданных в Variable View (Value Labels, Missing Values, Variable Type) | **$460 \times 380\text{ px}$** | Специфическая форма свойств с переключателями режимов и списком значений |
| **Type 4: Compute & Transform** | Вычисление выражений, рекодирование, фильтрация | **$620 \times 480\text{ px}$** | Расширенное окно с калькулятором, деревом функций и списком аргументов |

## 2. Сетка, отступы и геометрия (Grid & Spacing)

### 2.1. Внешние и внутренние отступы
* **Outer Window Margin / Padding:** $12\text{ px}$ со всех четырех сторон окна.
* **Column Gap:** $8\text{ px}$ между списками и панелью переноса; $12\text{ px}$ перед правой колонкой поддиалогов.
* **Vertical Gap:** $8\text{ px}$ между логическими строками внутри блоков, $12\text{ px}$ между крупными блоками.
* **Separators:** тонкая разделительная линия `Tokens::BORDER` толщиной $1\text{ px}$ над нижней панелью кнопок с отступом $8\text{ px}$ сверху и снизу.

### 2.2. Размеры панелей в Type 1 (SPSS 3-Column Layout)
* **Левая панель (Available Variables):** ширина $200\text{ px}$, высота $240\text{ px}$. Включает заголовок `Variables:` и рамку со списком `Tokens::BG_PANEL`.
* **Центральный разделитель (Transfer Zone):** ширина $36\text{ px}$, центрированная адаптивная кнопка переноса $28 \times 28\text{ px}$.
* **Центральная панель (Target Variables / Factors):** ширина $200\text{ px}$, высота $240\text{ px}$.
* **Правая колонка (Subdialog Sidebar):** ширина $94\text{ px}$, вертикальный стек кнопок $90 \times 24\text{ px}$ с зазором $6\text{ px}$.
* **Нижняя панель (Action Bar):** высота $36\text{ px}$, горизонтальный ряд кнопок действий с выравниванием по левому краю или по центру.

## 3. Кнопки и интерактивные элементы

### 3.1. Нижний Action Bar процедур (i18n Shield)
Каждый диалог статистической процедуры обязан содержать канонический набор кнопок в строгом порядке:
1. `[ OK ]` — запуск процедуры (активна только при валидном наборе параметров `can_run == true`);
2. `[ Paste ]` — вставка синтаксиса `.sps` в буфер или Syntax Editor (активна при `can_run == true`);
3. `[ Reset ]` — сброс всех выбранных переменных и настроек к заводским дефолтам SPSS;
4. `[ Cancel ]` — закрытие окна без сохранения изменений;
5. `[ Help ]` — открытие контекстной справки.

**Правило «i18n Shield» (равная ширина с запасом):**
* Векторные и текстовые кнопки не должны «плясать» при переключении между английским (`OK`, `Paste`, `Reset`, `Cancel`) и русским (`OK`, `Вставить`, `Сброс`, `Отмена`) языками.
* Вычисляется ширина текста для каждой кнопки; все кнопки ряда получают **единую фиксированную ширину** $\max(\text{text\_width}) + 20\text{ px}$ (не менее $80\text{ px}$ ширины и $26\text{ px}$ высоты).
* Скругление углов: строго $3.0\text{ px}$.

### 3.2. Нижняя панель поддиалогов (Subdialog Action Bar)
Поддиалоги модальных настроек содержат 3 кнопки:
1. `[ Continue ]` — применение настроек и возврат в родительское окно;
2. `[ Cancel ]` — отмена изменений в поддиалоге;
3. `[ Help ]` — справка по параметрам.
Минимальный размер кнопок: $80 \times 26\text{ px}$, скругление $3.0\text{ px}$.

### 3.3. Кнопка переноса (Transfer Button)
* Одиночная квадратная кнопка $28 \times 28\text{ px}$ со скруглением $3.0\text{ px}$.
* Отрисовывается векторной стрелкой через `paint_vector_arrow`:
  * Направлена вправо `->`, когда фокус/выбор в левом списке;
  * Автоматически разворачивается влево `<-`, когда фокус/выбор в правом (целевом) списке;
  * При отсутствии выбора — светло-серая (отключена, `Tokens::TEXT_MUTED`).
* При двойном клике на переменную в списке перенос происходит мгновенно без нажатия кнопки.

### 3.4. Правая колонка поддиалогов (Subdialog Sidebar)
* Кнопки: `[ Statistics... ]`, `[ Options... ]`, `[ Charts... ]`, `[ Define Groups... ]`.
* Фиксированный размер: $90 \times 24\text{ px}$.
* Текст центрирован, размер шрифта $11\text{ pt}$, скругление $3.0\text{ px}$.

## 4. Списки переменных и визуальные индикаторы (Vector-First)

* Каждый элемент списка переменных отображается в формате:
  `[Иконка шкалы] Метка переменной [Имя переменной]`
  (если метка отсутствует — только имя).
* Иконка шкалы (`Measure::Scale`, `Ordinal`, `Nominal`) рисуется строго векторно (`paint_measure_icon`) размером $14 \times 14\text{ px}$.
* Запрещены любые Unicode-эмодзи и псевдографика (строгое правило Раздела 8 `AGENTS.md`).
* Цвета фона строк:
  * Обычная строка: прозрачный;
  * Наведение: `Tokens::BG_HEADER`;
  * Выделение: `Tokens::ACCENT_MUTED` (или полупрозрачный `Tokens::ACCENT`);
  * Рамка фокуса: $1\text{ px}$ `Tokens::ACCENT`.

## 5. Модули DialogKit

Все диалоговые окна обязаны использовать компоненты из `crates/statcraft_app/src/dialogs/common/`:
* `DialogShell`: управление окном, центрированием, заголовком и модальностью;
* `VariablePicker`: двухпанельный список переменных с фильтрацией и Drag & Drop;
* `TransferButton`: векторная адаптивная кнопка переноса;
* `DialogActionBar`: нижний ряд кнопок Type 1 с защитой i18n Shield;
* `SubdialogActionBar`: нижний ряд кнопок Type 2 (`Continue / Cancel / Help`);
* `SubdialogSidebar`: правая колонка кнопок вызова настроек;
* `GroupBox`: рамка визуального объединения радио-кнопок и опций.

Прямое использование сырых кнопок `ui.button(...)` для системных действий и произвольных размеров окон запрещено линтером `cargo run -p xtask -j 1 -- design-guard`.
