# Руководство по функциональным возможностям StatCraft (v0.4.2)

Данный документ представляет собой полный исчерпывающий справочник всех реализованных возможностей, аналитических процедур, алгоритмов и интерфейсных инструментов статистического пакета **StatCraft**.

---

## 1. Управление данными и двусторонний редактор

StatCraft предоставляет каноническое рабочее пространство с мгновенным переключением между представлением наблюдений (**Data View**) и словарем метаданных (**Variable View**).

### 1.1. Импорт и создание данных
* **Потоковый загрузчик CSV / TSV:** высокопроизводительный потоковый ридер с автоматическим выводом типов данных, поддержкой различных разделителей колонок (запятая, точка с запятой, табуляция) и форматов десятичных дробей.
* **Импорт файлов Microsoft Excel (`.xlsx`, `.xls`, `.ods`):** прямое чтение книг через открытый движок Calamine с санитизацией заголовков по стандарту имен SPSS и типизацией значений.
* **Режим «Чистый лист» (`Blank Dataset`):** создание новой пустой матрицы наблюдений (по умолчанию 40 строк) для ввода данных вручную без открытия внешнего файла.

### 1.2. Редактор данных (Data View — 4-квадрантная 2D-сетка)
* **Пространственная архитектура 4 квадрантов:** Закрепленный верхний левый угол (`quad_top_left`), колоночные заголовки (`quad_top_right`), номера строк (`quad_bottom_left`) и центральная область ячеек (`quad_center`). Номера строк остаются закрепленными при горизонтальной прокрутке.
* **Префиксная пространственная индексация (`LineIndex`):** $O(\log N)$ бинарный поиск ячеек с нулевыми аллокациями памяти на куче в режиме `Uniform`.
* **Интерактивный ресайз столбцов и автоподбор (Auto-fit):** Перетаскивание границы колонок с направляющей линией; двойной клик по разделителю подбирает ширину по содержимому; двусторонняя синхронизация со словарем SPSS (`VariableMetadata.columns`).
* **Прямоугольное выделение ячеек:** Выделение диапазона рамкой мыши, `Shift`-клик / `Shift`-drag с визуальным выделением активного курсора.
* **Сквозная навигация с клавиатуры:** Стрелки, Tab/Enter, прыжки к границам (`Home`/`End`, `Ctrl+Home`/`Ctrl+End`), расширение через Shift и **Direct Typing** (нажатие буквенно-цифровых клавиш сразу открывает инлайн-редактор без предварительного клика мышью).
* **Фокусируемый инлайн-редактор:** Плавающее текстовое поле `TextEdit` поверх ячейки с акцентной рамкой фокуса, автосохранением по Enter/Tab и отменой по Escape.
* **Прямоугольный буфер обмена TSV/CSV:** Двусторонний обмен (`Ctrl+C` / `Ctrl+V`) с Excel, Google Sheets и LibreOffice с авторасширением строк датасета.
* **Серийное автозаполнение (Fill Handle):** Векторный маркер протяжки в углу выделения рассчитывает шаг арифметической прогрессии для чисел и циклическое повторение для текстовых категорий.
* **Колоночный автофильтр:** Векторная кнопка в заголовке с шевроном/воронкой открывает всплывающее окно с живым поиском, чекбоксами и категорией «(Пустые)».
* **Быстрая сортировка через CommandBus:** Сортировка по возрастанию (A–Z) и убыванию (Z–A) через каноническую команду `data.sort_cases` со 100% обратимым Undo/Redo и выводом в синтаксис SPSS (`SORT CASES BY ...`).
* **Контекстное меню ячеек (правый клик):** Меню для фильтрации по значению ячейки, очистки фильтра столбца, быстрой сортировки и операций буфера обмена.
* **Визуализация фильтрации (Паритет SPSS FILTER BY):** Диагональное перечеркивание номеров отфильтрованных строк и приглушенный серый текст в ячейках.
* **Контроль целостности данных:** Автоматическое обнаружение чисел, сохраненных как текст (`is_number_stored_as_text`), с зеленым треугольником в углу ячейки и мгновенной конвертацией в число по клику.
* **Отображение меток значений (`1/A`):** Мгновенное переключение всей таблицы между числовыми кодами и читаемыми текстовыми метками значений.
* **Авторазогрев строк:** Автоматическое добавление новых наблюдений при заполнении последней строки таблицы.

### 1.3. Редактор переменных (Variable View)
Полноценный словарь метаданных переменных по стандарту IBM SPSS Statistics:
* **Имя (`Name`):** валидация идентификаторов по каноническим правилам SPSS (буквенный старт, запрет служебных символов и пробелов).
* **Тип (`Type`):** поддержка всех 9 канонических типов данных:
  1. *Numeric* (Стандартное числовое);
  2. *Comma* (Числовое с разделением тысяч запятыми и десятичной точкой);
  3. *Dot* (Числовое с разделением тысяч точками и десятичной запятой);
  4. *Scientific* (Экспоненциальная научная нотация `1.23E+02`);
  5. *Date* (Календарные даты в форматах `dd.mm.yyyy`, `yyyy-mm-dd` и др.);
  6. *Dollar* (Денежный формат с префиксом доллара `\$`);
  7. *Custom Currency* (Пользовательские валюты);
  8. *String* (Текстовые строковые переменные);
  9. *Restricted Numeric* (Числовые значения с фиксированным числом лидирующих нулей).
* **Разрядность и точность (`Width` & `Decimals`):** визуальные спиннеры `▲ / ▼` для быстрой настройки длины поля и количества знаков после запятой.
* **Метка переменной (`Label`):** развернутое описательное название переменной, отображаемое в заголовках таблиц вывода.
* **Метки значений (`Values`):** модальный диалог настройки соответствия между числовыми кодами и текстовыми метками категорий (например, `1 = "Мужской"`, `2 = "Женский"`).
* **Пропущенные значения (`Missing`):** гибкая настройка дискретных пользовательских пропусков (до 3 индивидуальных значений) и непрерывных диапазонов (например, `от 90 до 99`).
* **Выравнивание (`Align`):** настройка выравнивания в ячейках (*Влево / По центру / Вправо*).
* **Шкала измерения (`Measure`):** Номинальная (*Nominal*), Порядковая (*Ordinal*), Количественная (*Scale*) шкалы с аутентичными векторными пиктограммами.

## 2. Манипуляции и управление массивом (меню Data)

### 2.1. Мультифайловый воркспейс и параллельные сессии
* **Параллельные сессии документов (`WorkspaceManager`):**
  * Одновременное открытие, редактирование и переключение между несколькими наборами данных в едином окне программы с изолированными историями отмены/повтора (Undo/Redo), состояниями фильтров, расщепления файлов и выделения ячеек.
  * Сжатие таблиц в памяти без потерь: битовые маски пропусков (`NullBitmask`), словарное кодирование текстовых категорий (`DictionaryEncodedColumn`) и плотные числовые колонки (`LosslessCompressedColumn`) со 100% сохранением математической точности `f64`.
  * Команды управления датасетами в синтаксисе SPSS: `DATASET NAME`, `DATASET ACTIVATE`, `DATASET CLOSE`, `DATASET DISPLAY` с валидацией модификаторов `WINDOW=ASIS`.
* **Векторная панель вкладок документов (`DocumentTabStrip`):**
  * Вкладки с векторным значком таблицы, индикатором несохраненных изменений `*`, кнопкой закрытия `✕`, плавной прокруткой колесиком, кнопками навигации шевронами и кнопкой быстрого создания нового датасета `[ ➕ ]`.
  * Горячие клавиши: `Ctrl+Tab` / `Ctrl+Shift+Tab` (переключение между датасетами), `Ctrl+W` (закрыть текущий датасет).
  * **Прецизионные маркеры несохраненности:** Корректное позиционирование звездочки `*` строго справа за текстом (`text_x + text_w + 3.0`) с вертикальным центрированием `Align2::LEFT_CENTER` и резервированием отступа (32 px), исключающее наложение на буквы названия файла.
  * **Чистый заголовок окна:** Нормализованный заголовок окна `file_name` / `file_name *` без запрещенных символов Unicode.
* **Динамические цвета датасетов и персистентность в .stc (Spec-Kit 015):**
  * Генератор контрастных случайных цветов на базе SplitMix64 с угловым шагом $\ge 45^\circ$ по золотому сечению ($137.50777^\circ$), предотвращающий визуальное слияние вкладок со схожими именами (`merge_base.csv`, `merge_add_cases.csv`, `merge_add_vars.csv`).
  * Сквозная привязка цветов: активное подчеркивание вкладок, векторная иконка сетки, бейджи процедур в Outline Tree и сводная таблица Notes в Output Viewer.
  * Полное сохранение цветов в файлах проекта `.stc` со 100% обратной совместимостью со старыми файлами.
* **Кроссплатформенный Memory Guard (`system_memory.rs`):**
  * Нативный опрос доступной физической памяти ОС: Windows API (`GlobalMemoryStatusEx`), Linux (`/proc/meminfo`), macOS (`sysctl`), WebAssembly.
  * Предохранитель перед открытием файлов >250 MB или пакетов >10 файлов при нехватке RAM (<500 MB или <15%).

### 2.2. Слияние файлов: Добавить наблюдения и Добавить переменные (Feature 012)
* **Добавить наблюдения (`ADD FILES`):**
  * Вертикальное объединение строк из внешних файлов (`.sav`, `.zsav`, `.stc`, `.csv`, `.xlsx`) или соседних открытых вкладок.
  * Автоматическое сопоставление одноименных полей, приведение типов, отслеживание источника `/IN=var` и опциональная сортировка с чередованием по ключам `/BY`.
* **Добавить переменные (`MATCH FILES`):**
  * Горизонтальное объединение колонок: объединение 1:1 по ключам, справочные таблицы 1:N (`/TABLE`), последовательное слияние без ключей.
  * Автоматическое разрешение коллизий дублирующихся имен переменных и создание индикаторов присутствия (`/IN`).
* **Диалоговые окна стандарта DialogKit:**
  * Окна `AddCasesDialog` и `AddVarsDialog` с удобным двухколоночным выбором переменных, селектором открытых вкладок воркспейса, кнопкой обзора файлов на диске и генерацией канонического синтаксиса SPSS.

### 2.3. Сортировка, выборка и взвешивание наблюдений
* **Сортировка наблюдений (`Sort Cases`):**
  * Многоуровневая стабильная сортировка по неограниченному числу колонок.
  * Индивидуальный порядок сортировки для каждого ключа: по возрастанию (*Ascending*) или по убыванию (*Descending*).
  * Строгое следование канону SPSS: системные пропуски (`SYSMIS`, `NaN`) идут первыми при сортировке по возрастанию и последними при сортировке по убыванию.
* **Выборка наблюдений (`Select Cases`):**
  * Фильтрация на базе условных логических выражений через модальный калькулятор условий.
  * Режим фильтрации через создание служебной бинарной переменной `filter_$` с сохранением исключенных строк.
  * Режим перманентного удаления не прошедших условие наблюдений.
  * Векторный индикатор статуса `Filter: ON (var)` в строке состояния.
* **Расщепление файла (`Split File`):**
  * Анализ данных в разрезе категориальных подгрупп (до нескольких группирующих переменных).
  * Режимы: *Compare groups* (сравнение групп в объединенных таблицах) и *Organize output by groups* (разнесение вывода по отдельным блокам).
  * Векторный индикатор `Split File: ON (var)` в строке состояния.
* **Взвешивание наблюдений (`Weight Cases`):**
  * Частотное и выборочное взвешивание наблюдений по значениям числовой переменной весов.
  * Автоматический учет весов во всех дескриптивных, частотных и параметрических процедурах программы.
  * Векторный индикатор `Weight: ON (var)` в строке состояния.

## 3. Преобразование данных (меню Transform)

Все процедуры преобразования оснащены стандартизированными диалогами `DialogKit`, генерацией синтаксиса и поддержкой отката изменений `Undo` (`Ctrl+Z`):

* **Вычисление переменных (`Compute Variable`):**
  * Вычисление значений новых или перезапись существующих колонок по математическим формулам.
  * Встроенный парсер выражений на базе алгоритма Дейкстры (Shunting-yard / RPN).
  * Поддержка операций сложения, вычитания, умножения, деления, возведения в степень (`**`, `^`) и унарных знаков.
  * Встроенная библиотека функций: арифметические (`ABS`, `EXP`, `LN`, `LOG10`, `RND`, `SQRT`, `TRUNC`) и статистические (`SUM`, `MEAN`, `MIN`, `MAX`).
* **Перекодирование в те же переменные (`Recode into Same Variables`):**
  * Замена исходных значений переменной по заданному набору правил без создания новых колонок.
* **Перекодирование в другие переменные (`Recode into Different Variables`):**
  * Создание новых переменных на основе перекодирования старых.
  * Поддиалог *Old and New Values*: поддержка точных значений, диапазонов (*Range*), диапазонов от наименьшего (*Range Lowest through...*) и до наибольшего (*Range... through Highest*), системных и пользовательских пропусков, а также правила для всех остальных значений (*All other values*).
* **Автоматическое перекодирование (`Automatic Recode`):**
  * Преобразование строковых или произвольных числовых категорий в последовательные целые числа $1, 2, \dots, K$.
  * Автоматическое создание меток значений из исходных строковых или числовых данных.
  * Направление кодирования: от меньшего к большему (*Lowest value*) или от большего к меньшему (*Highest value*).
* **Сдвиг значений (`Shift Values`):**
  * Создание лаговых (*Lag*) и лидовых (*Lead*) временных колонок со сдвигом на заданное число шагов $K$.
* **Подсчет значений в наблюдениях (`Count Values within Cases`):**
  * Подсчет количества вхождений целевых значений или диапазонов по набору переменных для каждого наблюдения.
* **Создание дамми-переменных (`Create Dummy Variables` / One-Hot Encoding):**
  * Генерация бинарных индикаторов (0/1) для категориальных признаков.
  * Настройка корня имени, префикса и опция исключения референтной категории ($k-1$ признаков для линейных моделей).
* **Управление генератором случайных чисел (`Set Random Number Seed`):**
  * Фиксация глобального генератора псевдослучайных чисел для воспроизводимости выборок и расчетов.
* **Восполнение пропущенных значений (`Replace Missing Values`):**
  * Методы импутации: среднее ряда (*Series Mean*), среднее окрестности (*Mean of nearby points*), медиана окрестности (*Median of nearby points*), линейная интерполяция (*Linear interpolation*), линейный тренд (*Linear trend at point*).
* **Создание временных рядов (`Create Time Series`):**
  * Простые разности первого порядка (`DIFF`), сезонные разности (`SDIFF`), скользящее среднее (`SMA`), кумулятивные суммы (`CSUM`).
* **Визуальная дискретизация (`Visual Binning`):**
  * Разбиение непрерывной шкалы на интервалы: равной ширины, равных перцентилей (равные квантили выборки), стандартных отклонений от среднего.
  * Автоматическое формирование меток интервалов вида `< 20`, `20 - 40`, `> 40`.
* **Оптимальная дискретизация (`Optimal Binning`):**
  * Контролируемое разбиение числового предиктора относительно категориального отклика по алгоритму MDLP Файяда и Ирани на базе энтропии Шеннона.
* **Ранжирование наблюдений (`Rank Cases`):**
  * Присвоение рангов с обработкой связок: средний ранг (*Mean / Mid-ranks*), наименьший ранг (*Low*), наибольший ранг (*High*), последовательный (*Sequential*).
  * Типы рангов: простые ранги, дробные ранги, проценты, разбиение на N-тили, нормальные метки (Блом, Тьюки, Ранкит, Ван дер Варден) с аппроксимацией Акклама ($\le 1.15 \times 10^{-9}$).
* **Мастер даты и времени (`Date and Time Wizard`):**
  * Извлечение компонентов даты: год, месяц, день, час, минута, секунда, день недели, квартал.
  * Расчет интервала между двумя датами (`DATEDIFF`) в днях, месяцах или годах.
  * Прибавление или вычитание временных отрезков к датам (`DATESUM`).
* **Автоматическая подготовка данных (`Automated Data Preparation / ADP`):**
  * Комплексный пайплайн: скрининг неинформативных предикторов, обработка выбросов (винзоризация или замена на пропуски), масштабирование признаков (Z-score, Min-Max), слияние редких категорий, парные взаимодействия, разбиение на обучающую и тестовую выборки.
* **Программируемые преобразования (`Programmability Transformations`):**
  * Встроенный скриптовый редактор многострочных выражений.
  * Условные конструкции `IF ... THEN ... ELSE`, математические присваивания и проверка синтаксиса на лету с генерацией блока `BEGIN PROGRAM ... END PROGRAM.`.

## 4. Статистический анализ (меню Analyze)

Все математические процедуры StatCraft разработаны на **100% Safe Rust** и прошли строгую верификацию против академических эталонов `SciPy` и канона *IBM SPSS Statistics 24 Algorithms Guide* с абсолютной точностью $\le 10^{-6}$.

### 4.1. Описательные статистики и частотный анализ
* **Описательные статистики (`Descriptives`):**
  * Расчет рекуррентных моментов Спайсера (1972): $N$ валидных наблюдений, сумма, среднее, стандартная ошибка среднего, дисперсия, стандартное отклонение, размах, минимум, максимум, асимметрия (Skewness с SE), эксцесс Блисса (Kurtosis с SE).
  * Канонический UI на `DialogKit`: чекбокс «Сохранить стандартизованные значения в переменных», кнопки «Стиль...» (`TableStyleState`) и «Бутстреп...» в боковой панели, а также сгруппированный поддиалог «Описательные: Параметры» (`Среднее`, `Сумма`, блоки `Разброс`, `Распределение`, `Порядок вывода`).
  * Сохранение стандартизованных Z-оценок (`/SAVE`, создание переменных `Z<var>` или `ZSC001+` при коллизии с поддержкой `Undo`), сортировка вывода (`/SORT=MEAN|NAME (A)|(D)`), режим `MISSING=LISTWISE` с точным `listwise_n` и полный round-trip синтаксиса SPSS (`SUM`, `ALL`, `SAVE`, `MISSING`, `SORT`).
  * Динамический Output Viewer и экспорт (`TSV`, `HTML`, `TXT`): вывод строго выбранных статистик (`N`, `Range`, `Minimum`, `Maximum`, `Sum`, `Mean`, `S.E. Mean`, `Std. Deviation`, `Variance`, `Skewness`, `SE Skewness`, `Kurtosis`, `SE Kurtosis`), итоговая строка `Valid N (listwise)` и условное форматирование ячеек по `TableStyleRule` со сводным отчетом стилей.
  * Поддиалог «Бутстреп» (`Percentile` / `BCa`, `Simple` / `Stratified`, зерно `MT19937`) с выводом `Bias`, `Std. Error` и доверительных интервалов в Output Viewer и TSV-экспорт.
* **Частоты (`Frequencies`):**
  * Аутентичные таблицы частот: абсолютные частоты, проценты от общего объема, валидные проценты (за вычетом пропусков), кумулятивные проценты.
  * Модальные поддиалоги DialogKit: «Статистика», «Диаграммы», «Формат» (выбор порядка, вывод по переменным, порог подавления таблиц с зависимой валидацией), «Стиль» и «Бутстреп» (`Percentile` / `BCa`, `Simple` / `Stratified`, зерно `MT19937`).
  * Сортировка категорий: по возрастанию/убыванию значений (`AVALUE`/`DVALUE`) или частот (`AFREQ`/`DFREQ`) с динамическим пересчетом кумулятивных процентов.
  * Порог подавления таблиц (`LIMIT(n)`): автоматическое отключение таблиц категорий при превышении заданного числа градаций $n$ с выводом уведомления в Output Viewer и сохранением сводной таблицы статистик и графиков.
  * Организация вывода нескольких переменных: `COMPARE` (единая сводная таблица по всем переменным, последовательные таблицы частот, отдельный узел графиков) vs `VARIABLE` (автономные последовательные блоки по каждой переменной: персональная статистика, таблица частот, диаграмма).
  * Расчет квартилей ($Q_1, Q_2, Q_3$) и произвольных перцентилей по стандарту HAVERAGE ($r = p(N+1)$).
  * Векторные диаграммы распределений: столбчатые, круговые диаграммы и гистограммы с наложением теоретической кривой Гаусса.
* **Таблицы сопряженности (`Crosstabs`):**
  * Диалог на базе DialogKit: `Строки`, `Столбцы`, пагинация `Слой 1 из N` (`Предыдущее`/`Следующее`), `Вывести кластеризованные столбчатые диаграммы`, `Не выводить таблицы` и 6 поддиалогов (`Точные...`, `Статистики...`, `Ячейки...`, `Формат...`, `Стиль...`, `Бутстреп...`).
  * Многослойные матрицы $R \times C$ (`layers` через цепочки `BY`), сортировка строк (`AVALUE`/`DVALUE`), подавление таблиц (`NOTABLES`) и флаг кластерных диаграмм.
  * Наблюдаемые и ожидаемые частоты, скрытие малых частот, z-тест пропорций столбцов (с поправкой Бонферрони), проценты по строкам/столбцам/итогу и 3 вида остатков (нестандартизованные, стандартизованные, скорректированные).
  * Хи-квадрат Пирсона ($\chi^2$), отношение правдоподобия ($G^2$), линейно-линейная связь, поправка Йейтса и точный критерий Фишера ($2 \times 2$), Монте-Карло Пейтфилда $r \times c$ и ограниченный точный тест $r \times c$.
  * Полный набор мер связи: $\phi$, $V$ Крамера, коэффициент сопряженности $C$, $\lambda$, $U$, $\gamma$, $d$ Сомерса, $\tau_b$ и $\tau_c$ Кендалла, $\eta$, $r$ Пирсона, $\rho$ Спирмена, $\kappa$ Коэна, оценка риска (OR/RR с 95% ДИ), МакНемара/Боукера и стратифицированный анализ $2 \times 2 \times K$ (Кохран, Мантель–Хензель, Бреслоу–Дэй, Тароне).

### 4.2. Сравнение средних и дисперсионный анализ (Compare Means)
*Примечание: все перечисленные ниже процедуры (`Means`, `One-Sample T Test`, `Independent-Samples T Test`, `Paired-Samples T Test`, `One-Way ANOVA`) поддерживают переиспользуемый поддиалог «Бутстреп» (`Percentile` / `BCa`, `Simple` / `Stratified`, зерно `MT19937`) с выводом `Bootstrap Specifications` и таблиц `Bias`/`Std. Error`/`CI` в Output Viewer и TSV-экспорт.*
* **Средние по группам (`Means Breakdown`):**
  * Декомпозиция статистик (среднее, объем, дисперсия, медиана, минимум, максимум) зависимой переменной в разрезе факторов.
  * Таблица дисперсионного анализа (межгрупповая, внутригрупповая и общая суммы квадратов, $df$, средние квадраты, $F$-критерий, значимость).
  * Меры ассоциации: коэффициенты $\eta$ (Eta) и $\eta^2$ (Eta Squared).
* **Одновыборочный T-критерий (`One-Sample T Test`):**
  * Проверка гипотезы о равенстве генерального среднего заданному эталону.
  * Степени свободы, двустороннее $p$-value через регуляризованную неполную бета-функцию, разность средних, 95% (или настраиваемый) доверительный интервал разности.
* **Т-критерий для независимых выборок (`Independent-Samples T Test`):**
  * Сравнение двух независимых групп с поддиалогом *Define Groups*.
  * Автоматический критерий равенства дисперсий Левена ($F$, Sig).
  * Параллельный расчет двух строк таблицы вывода: критерий Стьюдента (при равенстве дисперсий) и критерий Уэлча (при неравенстве дисперсий со степенями свободы Саттертуэйта).
* **Т-критерий для парных выборок (`Paired-Samples T Test`):**
  * Сравнение связанных наблюдений (до/после, повторные измерения).
  * Таблицы статистик пар, коэффициенты корреляции Пирсона внутри пар ($r$, Sig) и проверка разностей пар ($t$, $df$, доверительный интервал).
* **Однофакторный дисперсионный анализ (`One-Way ANOVA`):**
  * Критерий Фишера для сравнения нескольких групп.
  * Межгрупповые и внутригрупповые суммы квадратов ($SS$), средние квадраты ($MS$).
  * Критерий однородности дисперсий Левена.
  * Подробные дескриптивные статистики по каждой группе с доверительными интервалами.

### 4.3. Анализ корреляций (Correlate)
* **Парные корреляции (`Bivariate Correlations`):**
  * Коэффициент линейной корреляции Пирсона ($r$).
  * Ранговый коэффициент корреляции Спирмена ($\rho$).
  * Ранговый коэффициент корреляции Кендалла ($\tau_b$) со всеми тремя поправками на связки рангов ($v_0, v_1, v_2$).
  * Односторонние (1-tailed) и двусторонние (2-tailed) уровни значимости.
  * Автоматическая маркировка значимости звёздочками (`*` для $p < 0.05$, `**` для $p < 0.01$).
  * Вычисление кросс-произведений отклонений и ковариаций, режимы попарного (*Pairwise*) и построчного (*Listwise*) исключения пропусков.
  * Переиспользуемый поддиалог «Бутстреп» (`Percentile` / `BCa`, `Simple` / `Stratified`, зерно `MT19937`) для коэффициентов корреляции.
* **Частные корреляции (`Partial Correlations` / `PARTIAL CORR`):**
  * Оценка чистой линейной взаимосвязи между переменными при статистическом контроле одной или нескольких непрерывных ковариат.
  * Расчет частных корреляций первого и высших порядков через обращение подматрицы ковариаций.
  * Базовая матрица корреляций нулевого порядка для сравнения, степени свободы ($df = N - k - 2$) и двусторонние уровни значимости.

### 4.4. Непараметрические критерии (Nonparametric Tests)
* **Две независимые выборки (`Two Independent Samples`):**
  * Критерий Манна-Уитни $U$, сумма рангов Вилкоксона $W$.
  * Объединенное ранжирование с поправкой на совпадающие ранги (дробные средние ранги).
  * Расчет Z-оценки и асимптотической двусторонней значимости.
* **K независимых выборок (`K Independent Samples`):**
  * Критерий Краскела-Уоллиса $H$ с расчетом поправки на связки $H_{adj}$.
  * Асимптотическая значимость через распределение $\chi^2$ со степенями свободы $df = k - 1$.
* **Две связанные выборки (`Two Related Samples`):**
  * Знаково-ранговый критерий Вилкоксона (*Wilcoxon Signed-Rank Test*) со скорректированной дисперсией и непрерывной поправкой.
  * Критерий знаков (*Sign Test*) с точным биномиальным расчетом значимости через бета-функцию.

### 4.5. Регрессионный анализ (Regression)
* **Множественная линейная регрессия (`Linear Regression`):**
  * Классический метод наименьших квадратов (OLS) и взвешенный МНК (WLS).
  * Таблица *Model Summary*: множественный коэффициент $R$, $R^2$, скорректированный $R^2$, стандартная ошибка оценки.
  * Таблица *ANOVA*: суммы квадратов регрессии и остатков, средние квадраты, $F$-критерий Фишера, значимость.
  * Таблица коэффициентов *Coefficients*: нестандартизованные коэффициенты $B$ и их стандартные ошибки, стандартизованные коэффициенты $\beta$, $t$-критерии, уровни значимости, 95% доверительные интервалы.
  * Переиспользуемый поддиалог «Бутстреп» (`Percentile` / `BCa`, `Simple` / `Stratified`, зерно `MT19937`) для коэффициентов регрессии $B$.
  * Диагностика мультиколлинеарности: толерантность (*Tolerance*) и фактор инфляции дисперсии (*VIF*).
* **Бинарная логистическая регрессия (`Binary Logistic Regression` / `LOGISTIC REGRESSION`):**
  * Метод максимального правдоподобия через итеративно перевзвешенные наименьшие квадраты (IRLS).
  * Интерактивная валидация мощности зависимой переменной: динамическая проверка 2 категорий с автоматической блокировкой кнопок при выборе непрерывных/многоклассовых переменных.
  * Таблица омнибус-тестов коэффициентов модели *Omnibus Tests of Model Coefficients* ($\chi^2$, $df$, $p$-value).
  * Таблица качества модели *Model Summary*: $-2 \text{ Log Likelihood}$, псевдо-$R^2$ Кокса-Снелла и Найджелкерка.
  * Критерий согласия Хосмера-Лемешова (*Hosmer and Lemeshow Test*) с таблицей распределения по децилям риска.
  * Классификационная таблица *Classification Table* с настраиваемым порогом отсечения (по умолчанию 0.5): чувствительность, специфичность и общий процент корректных прогнозов.
  * Таблица коэффициентов уравнения *Variables in the Equation*: оценки $B$, стандартная ошибка SE, критерий Вальда $\chi^2$, степени свободы, значимость, отношение шансов $\text{Exp}(B)$ и 95% доверительный интервал для $\text{Exp}(B)$.
* **Мультиномиальная логистическая регрессия (`Multinomial Logistic Regression` / `NOMREG`):**
  * Численный алгоритм оптимизации Ньютона-Рафсона (Fisher Scoring) с бэктрекинг-поиском шага, численно устойчивой функцией `log-sum-exp` и регуляризацией Риджа $\lambda = 10^{-6}$ при мультиколлинеарности или квази-полном разделении классов (гарантия правила `Never Crash`).
  * Поддержка политомических зависимых переменных с выбором базовой референтной категории (последняя, первая или произвольное числовое значение).
  * Поддержка категориальных факторов с автоматическим созданием индикаторных контрастов (Indicator dummy coding) и непрерывных ковариат.
  * Интерактивная валидация мощности зависимой переменной в диалоге: автоматическая проверка $\ge 2$ категорий, блокировка запуска на некорректных данных с понятными подсказками.
  * Полный комплект из 7 аутентичных сводных таблиц IBM SPSS Pivot Tables:
    * *Case Processing Summary*: число и процент наблюдений в каждой категории зависимой переменной и факторов.
    * *Model Fitting Information*: $-2 \text{ Log Likelihood}$, $\chi^2$, степени свободы и значимость модели против нулевой.
    * *Goodness-of-Fit*: критерии согласия Пирсона и девианса по субпопуляциям.
    * *Pseudo R-Square*: коэффициенты детерминации Кокса-Снелла, Найджелкерка и Макфаддена.
    * *Likelihood Ratio Tests*: тесты отношения правдоподобия для каждого эффекта модели.
    * *Parameter Estimates*: параметры $B$, стандартные ошибки, статистика Вальда, степени свободы, значимость, отношение шансов $\text{Exp}(B)$ и 95% доверительные интервалы.
    * *Classification Table*: матрица соответствия наблюдаемых и предсказанных классов с общим процентом корректной классификации.
* **Подгонка кривых (`Curve Estimation` / `CURVEFIT`):**
  * Одновременное построение и сравнение 11 моделей регрессионных кривых: линейная, логарифмическая, обратная, квадратичная, кубическая, степенная, составная, S-образная, логистическая, роста и экспоненциальная.
  * Сводная таблица параметров *Model Summary & Parameter Estimates* с оценкой $R^2$, $F$, степеней свободы, $p$-значения, константы $b_0$ и коэффициентов кривизны $b_1, b_2, b_3$.

### 4.6. Анализ надежности шкалы (Scale)
* **Анализ надежности (`Reliability Analysis`):**
  * Коэффициент надежности $\alpha$ Кронбаха (Cronbach's Alpha) и $\alpha$ на основе стандартизованных пунктов.
  * Таблица *Item Statistics*: средние, стандартные отклонения и $N$ по каждому пункту.
  * Таблица *Item-Total Statistics*: среднее шкалы при удалении пункта, дисперсия шкалы при удалении пункта, скорректированная корреляция пункта с общим баллом, $\alpha$ Кронбаха при исключении пункта.
  * Общие описательные статистики суммарной шкалы (*Scale Statistics*).

### 4.7. Снижение размерности (Dimension Reduction)
* **Факторный анализ и метод главных компонент (`Factor Analysis / PCA`):**
  * Метод главных компонент (PCA) через циклический спектральный решатель Якоби для собственных значений и собственных векторов корреляционной матрицы.
  * Мера адекватности выборки Кайзера-Мейера-Олкина (KMO).
  * Критерий сферичности Бартлетта (Bartlett's Test of Sphericity) с точным расчетом $\chi^2$ и $p$-value.
  * Таблица общностей (*Communalities*): начальные и после извлечения.
  * Таблица объясненной дисперсии (*Total Variance Explained*): собственные значения, % объясненной дисперсии и кумулятивный процент.
  * Матрица компонентных нагрузок (*Component Matrix*).

### 4.8. Общая линейная модель (GLM)
* **Одномерный дисперсионный и ковариационный анализ (`Univariate ANOVA` / `UNIANOVA`):**
  * Общая линейная модель с фиксированными факторами, случайными факторами и непрерывными ковариатами (ANCOVA).
  * Таблица межгрупповых эффектов *Tests of Between-Subjects Effects*: скорректированная модель, свободный член, главные эффекты, взаимодействия факторов и ковариат, ошибка, полный итог.
  * Суммы квадратов типа I и типа III ($SS$), степени свободы ($df$), средние квадраты ($MS$), статистика $F$, значимость и частная эта-квадрат ($\eta_p^2$).
  * Критерий однородности дисперсий Левена (*Levene's Test*).
* **Многомерный дисперсионный анализ (`Multivariate MANOVA` / `GLM Multivariate`):**
  * Одновременный анализ нескольких зависимых переменных по факторным группам и ковариатам.
  * Канонические многомерные критерии: Лямбда Уилкса ($\Lambda$), След Пиллая, След Хотеллинга и Наибольший корень Роя.
  * Многомерные аппроксимации $F$-критерия, степени свободы гипотезы и ошибки, значимость и частная $\eta_p^2$.
  * Последующие одномерные тесты межгрупповых эффектов по каждой зависимой переменной.
* **Дисперсионный анализ с повторными измерениями (`Repeated Measures ANOVA` / `GLM Repeated Measures`):**
  * Анализ внутригрупповых факторов повторных измерений и экспериментальных воздействий.
  * Критерий сферичности Мочли (*Mauchly's Test of Sphericity*) ($W$, приближенный $\chi^2$, $df$, Sig).
  * Автоматические поправки на нарушение сферичности: Гринхауза-Гейссера ($\hat{\epsilon}$), Хюйнха-Фельдта ($\tilde{\epsilon}$) и нижняя граница (Lower-bound).
  * Таблица внутригрупповых эффектов *Tests of Within-Subjects Effects* по четырем предпосылкам: сферичность соблюдена, Гринхауз-Гейссер, Хюйнх-Фельдт и нижняя граница.

### 4.9. Кластерный анализ (Classify)
* **Кластерный анализ методом K-средних (`K-Means Cluster Analysis` / `QUICK CLUSTER`):**
  * Быстрое разбиение массива наблюдений на $K$ непересекающихся кластеров по евклидову расстоянию (алгоритм Ллойда).
  * Настраиваемое количество кластеров $K$, лимит итераций и критерий сходимости.
  * Таблицы начальных центров кластеров (*Initial Cluster Centers*) и протокола итераций (*Iteration History*).
  * Таблица финальных центров кластеров (*Final Cluster Centers*) и межкластерных расстояний.
  * Таблица дисперсионного анализа *ANOVA* с межкластерными и внутрикластерными средними квадратами ($F$, Sig) для оценки дифференцирующей силы признаков.
  * Таблица распределения наблюдений по кластерам (*Number of Cases in Each Cluster*).

### 4.10. Сводные отчеты (Reports)
* **Книга кодов (`Codebook` / `CODEBOOK`):**
  * Комплексный сводный словарь метаданных для аудита и документирования структуры переменных массива.
  * Блок метаданных: имя, метка, тип хранения, формат вывода, шкала измерения и пользовательские пропуски.
  * Для категориальных шкал: метки значений, числовые коды, валидные частоты и проценты.
  * Для непрерывных шкал: число валидных наблюдений $N$, среднее значение, стандартное отклонение и квартили ($Q_1, Q_2, Q_3$).
* **Сводка по наблюдениям (`Case Summaries` / `SUMMARIZE`):**
  * Построчный листинг наблюдений и дескриптивные сводки по группам классифицирующих факторов.
  * Опциональный вывод отдельных строк с ограничением первых $N$ наблюдений.
  * Групповые статистики: общее число наблюдений $N$, среднее, медиана, стандартное отклонение, дисперсия, сумма, минимум, максимум и процент от общего объема выборки.

### 4.11. Анализ выживаемости (Survival)
* **Анализ выживаемости Каплана-Мейера (`Kaplan-Meier` / `KM`):**
  * Непараметрическая оценка функций выживания и кумулятивных кривых дожития во времени.
  * Переменная времени до наступления события и категориальная переменная статуса (с заданием кода события или диапазона).
  * Подробная таблица дожития *Survival Table*: время события, статус (наступление события / цензурирование), кумулятивная вероятность выживания, стандартная ошибка, накопленное число событий и число оставшихся под наблюдением.
  * Оценки среднего и медианного времени жизни со стандартными ошибками и 95% доверительными интервалами.
  * Статистическое сравнение факторов: Лог-ранговый критерий Мантеля-Кокса ($\chi^2, df, p$), критерий Бреслоу (обобщенный Вилкоксон) и критерий Тароне-Уэра.
* **Актуарные таблицы дожития (`Life Tables` / `SURVIVAL`):**
  * Интервальный анализ таблиц смертности и дожития для больших когорт и демографических исследований.
  * Настройка начала, окончания и шага временных интервалов.
  * Канонические колонки актуарной таблицы: число вступивших в интервал, число выбывших (цензурированных), число подверженных риску, число терминальных событий, доля умерших, доля выживших, кумулятивная доля доживших до конца интервала, плотность вероятности, интенсивность отказов (Hazard Rate) и медианное время дожития.
  * Межгрупповое сравнение выборок с помощью критерия Вилкоксона (Гехана).
* **Регрессия пропорциональных рисков Кокса (`Cox Regression` / `COXREG`):**
  * Полупараметрическое моделирование времени до наступления события с непрерывными и дискретными ковариатами.
  * Максимизация логарифмического частичного правдоподобия (Partial Likelihood) методом Ньютона-Рафсона с бэктрекинг-контролем шага и гарантией Never Crash.
  * Обработка одновременных событий (Ties): канонический метод Бреслоу (Breslow, по умолчанию в SPSS) и метод Эфрона (Efron).
  * Поддержка клинической стратификации: единый вектор параметров $\beta$ при раздельных стратифицированных базовых функциях риска.
  * Аутентичные сводные таблицы IBM SPSS Pivot Tables:
    * *Case Processing Summary*: общее число наблюдений $N$, события, цензурированные случаи и доли по каждой страте и всего.
    * *Omnibus Tests of Model Coefficients*: критерий согласия $-2 \text{ Log Likelihood}$, $\chi^2$, степени свободы и значимость.
    * *Variables in the Equation*: коэффициенты $B$, стандартные ошибки SE, статистика Вальда $\chi^2$, степени свободы, значимость, отношение рисков $\text{Exp}(B)$ и 95% доверительные интервалы для $\text{Exp}(B)$.
    * *Survival Table at Mean of Covariates*: накопленный базовый риск $\hat{H}_0(t)$, базовая выживаемость $\hat{S}_0(t)$ и функция дожития при средних значениях ковариат.
  * Векторный ступенчатый график функции выживаемости (Survival Plot) на базе дизайн-токенов.

## 7. Готовность к взаимодействию с ИИ (Agent-Ready) и мост Model Context Protocol (MCP)

StatCraft оснащен встроенным нативным сервером **Model Context Protocol (MCP)** и сетевым IPC-мостом, позволяющим современным ИИ-ассистентам (Antigravity, Claude, ChatGPT, локальным LLM) программно взаимодействовать с программой и запускать автоматизированные аналитические пайплайны.

* **Два режима работы моста:**
  * **Консольный автономный сервер (`statcraft --mcp`):** JSON-RPC транспорт через стандартный ввод/вывод (stdio), полностью соответствующий открытому стандарту Model Context Protocol. Позволяет внешним агентам исследовать структуру переменных, запускать тесты и строить модели без отображения графического окна.
  * **Прямой мост к графическому окну (Порт 18493):** Фоновый локальный сервер, позволяющий внешним ассистентам напрямую взаимодействовать с запущенным десктопным интерфейсом (`Расширения -> Мост MCP / Copilot`), динамически обновляя данные в Data View и вставляя аналитические выкладки в реальном времени.
* **Базовый арсенал инструментов MCP:**
  * `get_dataset_info`: Возвращает полную JSON-структуру активного датасета: объем выборки $N$, число признаков $P$, имена колонок, шкалы измерения, правила пропусков и словари меток значений.
  * `execute_syntax`: Принимает скрипты канонического синтаксиса SPSS (`.sps`), выполняет их на движке `CommandBus` и возвращает структурированный протокол с таблицами результатов и логом.
  * `insert_report`: Динамически генерирует и вставляет в дерево Output Viewer аналитические эссе в формате Markdown, клинические интерпретации и управленческие выводы.
* **Схемы параметров для агентов (`specs()`):**
  * Каждая команда движка (`statcraft_syntax`) экспортирует строгую схему аргументов через `specs()`, что гарантирует безошибочную генерацию параметров нейросетями без галлюцинаций.

## 8. Дизайн-система, надежность, локализация и темы оформления

* **Универсальный движок тем оформления (Tokens):**
  * Три тщательно откалиброванных визуальных стиля:
    * **Темная Pro (Dark Pro — по умолчанию):** Высококонтрастная эргономичная темная тема для комфортного ввода данных и ночной работы без бликов.
    * **Классическая светлая SPSS (SPSS Classic Light):** Аутентичная светлая палитра классического интерфейса IBM SPSS Statistics.
    * **Системная (System Auto):** Автоматическая адаптация под системную тему операционной системы.
* **Жизненный цикл вкладок док-системы:**
  * **Защищенные системные вкладки:** Главные вкладки активного датасета (*«Представление данных»* и *«Представление переменных»*) лишены кнопки закрытия `[x]`, что исключает случайное удаление базовых окон.
  * **Закрываемые дополнительные вкладки:** Динамические вкладки редактора синтаксиса и вторичные окна вывода создаются, разделяются и закрываются по клику на `[x]`.
  * **Управление окнами через меню:** Меню `Окно` для мгновенного поиска и фокуса на любом открытом пространстве.
* **Гарантия «Never Crash» (100% Safe Rust):**
  * Полный отказ от `unsafe`, `panic!`, `unwrap()` и `expect()`. Любые некорректные пользовательские вводы, сингулярные матрицы, пустые выборки или деление на ноль возвращают типизированную ошибку и системные пропуски, предотвращая аварийное закрытие программы.
* **Векторный интерфейс (Vector-First UI):**
  * Полный отказ от растровых иконок и Unicode-эмодзи, гарантирующий отсутствие квадратов «тофу» (`□`) в любых дистрибутивах ОС.
  * Векторная отрисовка графических примитивов через `ui.painter()` и аппаратная растеризация SVG-иконок под системный DPI монитора.
* **Нулевой хардкод строк и мгновенная локализация:**
  * 100% строк вынесены в каталоги Fluent (`locales/ru.ftl`, `locales/en.ftl`).
  * Переключение языка интерфейса (Русский $\leftrightarrow$ Английский) на лету без перезапуска приложения.
* **Кроссплатформенность:**
  * Официальная поддержка и единая кодовая база для Windows (x64), Linux (x64) и macOS (Apple Silicon ARM64 & Intel x64).
