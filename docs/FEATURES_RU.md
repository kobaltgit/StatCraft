# Руководство по функциональным возможностям StatCraft (v0.2.2)

Данный документ представляет собой полный исчерпывающий справочник всех реализованных возможностей, аналитических процедур, алгоритмов и интерфейсных инструментов статистического пакета **StatCraft**.

---

## 1. Управление данными и двусторонний редактор

StatCraft предоставляет каноническое рабочее пространство с мгновенным переключением между представлением наблюдений (**Data View**) и словарем метаданных (**Variable View**).

### 1.1. Импорт и создание данных
* **Потоковый загрузчик CSV / TSV:** высокопроизводительный потоковый ридер с автоматическим выводом типов данных, поддержкой различных разделителей колонок (запятая, точка с запятой, табуляция) и форматов десятичных дробей.
* **Импорт файлов Microsoft Excel (`.xlsx`, `.xls`, `.ods`):** прямое чтение книг через открытый движок Calamine с санитизацией заголовков по стандарту имен SPSS и типизацией значений.
* **Режим «Чистый лист» (`Blank Dataset`):** создание новой пустой матрицы наблюдений (по умолчанию 40 строк) для ввода данных вручную без открытия внешнего файла.

### 1.2. Редактор данных (Data View)
* **Виртуализированный грид:** плавная прокрутка десятков тысяч строк и сотен колонок на базе `ScrollArea::show_rows`.
* **Инлайн-редактирование:** прямой ввод значений в ячейки по клавишам `Enter` (переход вниз) и `Tab` (переход вправо) с автоматической нормализацией разделителей.
* **Авторазогрев строк:** автоматическое создание новых наблюдений при заполнении последней строки таблицы.
* **Добавление и удаление строк:** контекстное меню строки и горячие клавиши для добавления (`Insert Case`) и удаления (`Delete Case`).
* **Отображение меток значений (`1/A`):** мгновенное переключение всей таблицы между числовыми кодами и читаемыми текстовыми метками значений.
* **Индикация активного фильтра:** диагональное векторное перечеркивание номеров строк, исключенных из анализа активной выборкой.

### 1.3. Редактор переменных (Variable View)
Полноценный словарь метаданных переменных по стандарту IBM SPSS Statistics:
* **Имя (`Name`):** валидация идентификаторов по каноническим правилам SPSS (буквенный старт, запрет служебных символов и пробелов).
* **Тип (`Type`):** поддержка всех 9 канонических типов данных:
  1. *Numeric* (Стандартное числовое);
  2. *Comma* (Числовое с разделением тысяч запятыми и десятичной точкой);
  3. *Dot* (Числовое с разделением тысяч точками и десятичной запятой);
  4. *Scientific* (Экспоненциальная научная нотация `1.23E+02`);
  5. *Date* (Календарные даты в форматах `dd.mm.yyyy`, `yyyy-mm-dd` и др.);
  6. *Dollar* (Денежный формат с префиксом доллара `\$`);
  7. *Custom Currency* (Пользовательские валюты);
  8. *String* (Текстовые строковые переменные);
  9. *Restricted Numeric* (Числовые значения с фиксированным числом лидирующих нулей).
* **Разрядность и точность (`Width` & `Decimals`):** визуальные спиннеры `▲ / ▼` для быстрой настройки длины поля и количества знаков после запятой.
* **Метка переменной (`Label`):** развернутое описательное название переменной, отображаемое в заголовках таблиц вывода.
* **Метки значений (`Values`):** модальный диалог настройки соответствия между числовыми кодами и текстовыми метками категорий (например, `1 = "Мужской"`, `2 = "Женский"`).
* **Пропущенные значения (`Missing`):** гибкая настройка дискретных пользовательских пропусков (до 3 индивидуальных значений) и непрерывных диапазонов (например, `от 90 до 99`).
* **Выравнивание (`Align`):** настройка выравнивания в ячейках (*Влево / По центру / Вправо*).
* **Шкала измерения (`Measure`):** Номинальная (*Nominal*), Порядковая (*Ordinal*), Количественная (*Scale*) шкалы с аутентичными векторными пиктограммами.

## 2. Манипуляции и управление массивом (меню Data)

* **Сортировка наблюдений (`Sort Cases`):**
  * Многоуровневая стабильная сортировка по неограниченному числу колонок.
  * Индивидуальный порядок сортировки для каждого ключа: по возрастанию (*Ascending*) или по убыванию (*Descending*).
  * Строгое следование канону SPSS: системные пропуски (`SYSMIS`, `NaN`) идут первыми при сортировке по возрастанию и последними при сортировке по убыванию.
* **Выборка наблюдений (`Select Cases`):**
  * Фильтрация на базе условных логических выражений через модальный калькулятор условий.
  * Режим фильтрации через создание служебной бинарной переменной `filter_$` с сохранением исключенных строк.
  * Режим перманентного удаления не прошедших условие наблюдений.
  * Векторный индикатор статуса `Filter: ON (var)` в строке состояния.
* **Расщепление файла (`Split File`):**
  * Анализ данных в разрезе категориальных подгрупп (до нескольких группирующих переменных).
  * Режимы: *Compare groups* (сравнение групп в объединенных таблицах) и *Organize output by groups* (разнесение вывода по отдельным блокам).
  * Векторный индикатор `Split File: ON (var)` в строке состояния.
* **Взвешивание наблюдений (`Weight Cases`):**
  * Частотное и выборочное взвешивание наблюдений по значениям числовой переменной весов.
  * Автоматический учет весов во всех дескриптивных, частотных и параметрических процедурах программы.
  * Векторный индикатор `Weight: ON (var)` в строке состояния.

## 3. Преобразование данных (меню Transform)

Все процедуры преобразования оснащены стандартизированными диалогами `DialogKit`, генерацией синтаксиса и поддержкой отката изменений `Undo` (`Ctrl+Z`):

* **Вычисление переменных (`Compute Variable`):**
  * Вычисление значений новых или перезапись существующих колонок по математическим формулам.
  * Встроенный парсер выражений на базе алгоритма Дейкстры (Shunting-yard / RPN).
  * Поддержка операций сложения, вычитания, умножения, деления, возведения в степень (`**`, `^`) и унарных знаков.
  * Встроенная библиотека функций: арифметические (`ABS`, `EXP`, `LN`, `LOG10`, `RND`, `SQRT`, `TRUNC`) и статистические (`SUM`, `MEAN`, `MIN`, `MAX`).
* **Перекодирование в те же переменные (`Recode into Same Variables`):**
  * Замена исходных значений переменной по заданному набору правил без создания новых колонок.
* **Перекодирование в другие переменные (`Recode into Different Variables`):**
  * Создание новых переменных на основе перекодирования старых.
  * Поддиалог *Old and New Values*: поддержка точных значений, диапазонов (*Range*), диапазонов от наименьшего (*Range Lowest through...*) и до наибольшего (*Range... through Highest*), системных и пользовательских пропусков, а также правила для всех остальных значений (*All other values*).
* **Автоматическое перекодирование (`Automatic Recode`):**
  * Преобразование строковых или произвольных числовых категорий в последовательные целые числа $1, 2, \dots, K$.
  * Автоматическое создание меток значений из исходных строковых или числовых данных.
  * Направление кодирования: от меньшего к большему (*Lowest value*) или от большего к меньшему (*Highest value*).
* **Сдвиг значений (`Shift Values`):**
  * Создание лаговых (*Lag*) и лидовых (*Lead*) временных колонок со сдвигом на заданное число шагов $K$.
* **Подсчет значений в наблюдениях (`Count Values within Cases`):**
  * Подсчет количества вхождений целевых значений или диапазонов по набору переменных для каждого наблюдения.
* **Создание дамми-переменных (`Create Dummy Variables` / One-Hot Encoding):**
  * Генерация бинарных индикаторов (0/1) для категориальных признаков.
  * Настройка корня имени, префикса и опция исключения референтной категории ($k-1$ признаков для линейных моделей).
* **Управление генератором случайных чисел (`Set Random Number Seed`):**
  * Фиксация глобального генератора псевдослучайных чисел для воспроизводимости выборок и расчетов.
* **Восполнение пропущенных значений (`Replace Missing Values`):**
  * Методы импутации: среднее ряда (*Series Mean*), среднее окрестности (*Mean of nearby points*), медиана окрестности (*Median of nearby points*), линейная интерполяция (*Linear interpolation*), линейный тренд (*Linear trend at point*).
* **Создание временных рядов (`Create Time Series`):**
  * Простые разности первого порядка (`DIFF`), сезонные разности (`SDIFF`), скользящее среднее (`SMA`), кумулятивные суммы (`CSUM`).
* **Визуальная дискретизация (`Visual Binning`):**
  * Разбиение непрерывной шкалы на интервалы: равной ширины, равных перцентилей (равные квантили выборки), стандартных отклонений от среднего.
  * Автоматическое формирование меток интервалов вида `< 20`, `20 - 40`, `> 40`.
* **Оптимальная дискретизация (`Optimal Binning`):**
  * Контролируемое разбиение числового предиктора относительно категориального отклика по алгоритму MDLP Файяда и Ирани на базе энтропии Шеннона.
* **Ранжирование наблюдений (`Rank Cases`):**
  * Присвоение рангов с обработкой связок: средний ранг (*Mean / Mid-ranks*), наименьший ранг (*Low*), наибольший ранг (*High*), последовательный (*Sequential*).
  * Типы рангов: простые ранги, дробные ранги, проценты, разбиение на N-тили, нормальные метки (Блом, Тьюки, Ранкит, Ван дер Варден) с аппроксимацией Акклама ($\le 1.15 \times 10^{-9}$).
* **Мастер даты и времени (`Date and Time Wizard`):**
  * Извлечение компонентов даты: год, месяц, день, час, минута, секунда, день недели, квартал.
  * Расчет интервала между двумя датами (`DATEDIFF`) в днях, месяцах или годах.
  * Прибавление или вычитание временных отрезков к датам (`DATESUM`).
* **Автоматическая подготовка данных (`Automated Data Preparation / ADP`):**
  * Комплексный пайплайн: скрининг неинформативных предикторов, обработка выбросов (винзоризация или замена на пропуски), масштабирование признаков (Z-score, Min-Max), слияние редких категорий, парные взаимодействия, разбиение на обучающую и тестовую выборки.
* **Программируемые преобразования (`Programmability Transformations`):**
  * Встроенный скриптовый редактор многострочных выражений.
  * Условные конструкции `IF ... THEN ... ELSE`, математические присваивания и проверка синтаксиса на лету с генерацией блока `BEGIN PROGRAM ... END PROGRAM.`.

## 4. Статистический анализ (меню Analyze)

Все математические процедуры StatCraft разработаны на **100% Safe Rust** и прошли строгую верификацию против академических эталонов `SciPy` и канона *IBM SPSS Statistics 24 Algorithms Guide* с абсолютной точностью $\le 10^{-6}$.

### 4.1. Описательные статистики и частотный анализ
* **Описательные статистики (`Descriptives`):**
  * Расчет рекуррентных моментов Спайсера (1972): $N$ валидных наблюдений, сумма, среднее, стандартная ошибка среднего, дисперсия, стандартное отклонение, размах, минимум, максимум, асимметрия (Skewness с SE), эксцесс Блисса (Kurtosis с SE).
* **Частоты (`Frequencies`):**
  * Аутентичные таблицы частот: абсолютные частоты, проценты от общего объема, валидные проценты (за вычетом пропусков), кумулятивные проценты.
  * Расчет квартилей ($Q_1, Q_2, Q_3$) и произвольных перцентилей по стандарту HAVERAGE ($r = p(N+1)$).
* **Таблицы сопряженности (`Crosstabs`):**
  * Построение двумерных матриц $R \times C$.
  * Вывод наблюдаемых и ожидаемых частот, остатков, процентов по строкам, столбцам и общему итогу.
  * Критерий независимости Хи-квадрат Пирсона ($\chi^2$), отношение правдоподобия (Likelihood Ratio $G^2$).
  * Поправка Йейтса на непрерывность и двусторонний точный критерий Фишера для таблиц $2 \times 2$.
  * Меры связи для номинальных шкал: коэффициент $\phi$ и $V$ Крамера.

### 4.2. Сравнение средних и дисперсионный анализ (Compare Means)
* **Средние по группам (`Means Breakdown`):**
  * Декомпозиция статистик (среднее, объем, дисперсия, медиана, минимум, максимум) зависимой переменной в разрезе факторов.
  * Таблица дисперсионного анализа (межгрупповая, внутригрупповая и общая суммы квадратов, $df$, средние квадраты, $F$-критерий, значимость).
  * Меры ассоциации: коэффициенты $\eta$ (Eta) и $\eta^2$ (Eta Squared).
* **Одновыборочный T-критерий (`One-Sample T Test`):**
  * Проверка гипотезы о равенстве генерального среднего заданному эталону.
  * Степени свободы, двустороннее $p$-value через регуляризованную неполную бета-функцию, разность средних, 95% (или настраиваемый) доверительный интервал разности.
* **Т-критерий для независимых выборок (`Independent-Samples T Test`):**
  * Сравнение двух независимых групп с поддиалогом *Define Groups*.
  * Автоматический критерий равенства дисперсий Левена ($F$, Sig).
  * Параллельный расчет двух строк таблицы вывода: критерий Стьюдента (при равенстве дисперсий) и критерий Уэлча (при неравенстве дисперсий со степенями свободы Саттертуэйта).
* **Т-критерий для парных выборок (`Paired-Samples T Test`):**
  * Сравнение связанных наблюдений (до/после, повторные измерения).
  * Таблицы статистик пар, коэффициенты корреляции Пирсона внутри пар ($r$, Sig) и проверка разностей пар ($t$, $df$, доверительный интервал).
* **Однофакторный дисперсионный анализ (`One-Way ANOVA`):**
  * Критерий Фишера для сравнения нескольких групп.
  * Межгрупповые и внутригрупповые суммы квадратов ($SS$), средние квадраты ($MS$).
  * Критерий однородности дисперсий Левена.
  * Подробные дескриптивные статистики по каждой группе с доверительными интервалами.

### 4.3. Анализ корреляций (Correlate)
* **Парные корреляции (`Bivariate Correlations`):**
  * Коэффициент линейной корреляции Пирсона ($r$).
  * Ранговый коэффициент корреляции Спирмена ($\rho$).
  * Ранговый коэффициент корреляции Кендалла ($\tau_b$) со всеми тремя поправками на связки рангов ($v_0, v_1, v_2$).
  * Односторонние (1-tailed) и двусторонние (2-tailed) уровни значимости.
  * Автоматическая маркировка значимости звёздочками (`*` для $p < 0.05$, `**` для $p < 0.01$).
  * Вычисление кросс-произведений отклонений и ковариаций, режимы попарного (*Pairwise*) и построчного (*Listwise*) исключения пропусков.

### 4.4. Непараметрические критерии (Nonparametric Tests)
* **Две независимые выборки (`Two Independent Samples`):**
  * Критерий Манна-Уитни $U$, сумма рангов Вилкоксона $W$.
  * Объединенное ранжирование с поправкой на совпадающие ранги (дробные средние ранги).
  * Расчет Z-оценки и асимптотической двусторонней значимости.
* **K независимых выборок (`K Independent Samples`):**
  * Критерий Краскела-Уоллиса $H$ с расчетом поправки на связки $H_{adj}$.
  * Асимптотическая значимость через распределение $\chi^2$ со степенями свободы $df = k - 1$.
* **Две связанные выборки (`Two Related Samples`):**
  * Знаково-ранговый критерий Вилкоксона (*Wilcoxon Signed-Rank Test*) со скорректированной дисперсией и непрерывной поправкой.
  * Критерий знаков (*Sign Test*) с точным биномиальным расчетом значимости через бета-функцию.

### 4.5. Линейная регрессия (Regression)
* **Множественная линейная регрессия (`Linear Regression`):**
  * Классический метод наименьших квадратов (OLS) и взвешенный МНК (WLS).
  * Таблица *Model Summary*: множественный коэффициент $R$, $R^2$, скорректированный $R^2$, стандартная ошибка оценки.
  * Таблица *ANOVA*: суммы квадратов регрессии и остатков, средние квадраты, $F$-критерий Фишера, значимость.
  * Таблица коэффициентов *Coefficients*: нестандартизованные коэффициенты $B$ и их стандартные ошибки, стандартизованные коэффициенты $\beta$, $t$-критерии, уровни значимости, 95% доверительные интервалы.
  * Диагностика мультиколлинеарности: толерантность (*Tolerance*) и фактор инфляции дисперсии (*VIF*).

### 4.6. Анализ надежности шкалы (Scale)
* **Анализ надежности (`Reliability Analysis`):**
  * Коэффициент надежности $\alpha$ Кронбаха (Cronbach's Alpha) и $\alpha$ на основе стандартизованных пунктов.
  * Таблица *Item Statistics*: средние, стандартные отклонения и $N$ по каждому пункту.
  * Таблица *Item-Total Statistics*: среднее шкалы при удалении пункта, дисперсия шкалы при удалении пункта, скорректированная корреляция пункта с общим баллом, $\alpha$ Кронбаха при исключении пункта.
  * Общие описательные статистики суммарной шкалы (*Scale Statistics*).

### 4.7. Снижение размерности (Dimension Reduction)
* **Факторный анализ и метод главных компонент (`Factor Analysis / PCA`):**
  * Метод главных компонент (PCA) через циклический спектральный решатель Якоби для собственных значений и собственных векторов корреляционной матрицы.
  * Мера адекватности выборки Кайзера-Мейера-Олкина (KMO).
  * Критерий сферичности Бартлетта (Bartlett's Test of Sphericity) с точным расчетом $\chi^2$ и $p$-value.
  * Таблица общностей (*Communalities*): начальные и после извлечения.
  * Таблица объясненной дисперсии (*Total Variance Explained*): собственные значения, % объясненной дисперсии и кумулятивный процент.
  * Матрица компонентных нагрузок (*Component Matrix*).

## 5. Модуль вывода и экспорта (Output Viewer)

* **Иерархическое дерево оглавления (Outline Pane):**
  * Древовидная панель слева со структурой документа по процедурам, журналу синтаксиса и отдельным таблицам.
  * Мгновенный переход к выбранной таблице при клике в дереве с мягкой подсветкой фокуса.
  * Синхронное автоматическое выделение узла в оглавлении при клике на таблицу в свитке.
  * Управление оглавлением: кнопки сворачивания/разворачивания веток, очистка всего вывода, удаление отдельных элементов по клавише `Delete`.
* **Аутентичные сводные таблицы (Pivot Tables):**
  * Точное воспроизведение геометрии и типографики IBM SPSS Statistics: вложенные многоярусные заголовки, чередующаяся подсветка строк, выравнивание чисел по правому краю, сноски критериев.
* **Экспорт в Microsoft Excel в один клик:**
  * Кнопка `[ Копировать таблицу (TSV) ]` в заголовке каждой таблицы.
  * Структурированный буфер обмена в формате Tab-Separated Values (TSV): вставляется в Excel или Google Sheets чисто, без сдвига колонок, искажения дат или слипания текста.
* **Журнал протокола (Log):**
  * Фиксация исполненных команд командного языка SPSS (`GET DATA`, `DESCRIPTIVES`, `CROSSTABS`, `REGRESSION` и др.) с отметками точного времени выполнения.

## 6. Синтаксический движок SPSS (`.sps`) и командная шина

* **Типизированная шина команд (`CommandBus`):**
  * Каждое действие в интерфейсе — это строгая команда движка (`EngineCommand`), снабженная схемой параметров для чтения ИИ-агентами (`specs()`).
* **Кнопка `[ Paste ]` во всех диалогах:**
  * Нажатие кнопки `[ Paste ]` в любом диалоговом окне генерирует соответствующую команду синтаксиса SPSS и помещает её в редактор синтаксиса или журнал.
* **Редактор синтаксиса (Syntax Editor):**
  * Встроенная вкладка ввода команд синтаксиса SPSS с моноширинным шрифтом и кнопками исполнения.
* **Поддержка отката изменений (`Undo / Redo`):**
  * Транзакционный буфер правок `DeltaBuffer` в памяти, позволяющий отменять и возвращать модификации данных и метаданных по `Ctrl+Z` / `Ctrl+Y`.

## 7. Готовность к взаимодействию с ИИ (Agent-Ready) и статус MCP-моста

* **Схемы параметров для агентов (`specs()`):**
  * Каждая процедура движка (`statcraft_syntax`) предоставляет типизированную JSON-схему параметров `specs()`, позволяющую внешним ИИ-агентам программно формировать корректные запросы и валидировать аргументы без графического интерфейса.
* **Пакетный запуск синтаксиса:**
  * ИИ-ассистенты могут генерировать канонический синтаксис SPSS (`.sps`) и запускать его через командную шину с полным сохранением протокола и таблиц вывода.
* **Статус прямого сетевого подключения (Мост MCP / IPC-сокет):**
  * *В разработке (`InDev` / Roadmap):* Встроенный сетевой IPC-сокет и нативный MCP-сервер для прямого удаленного управления запущенным GUI-окном программы в текущей версии v0.2.2 находятся в разработке (пункт меню `Расширения -> Мост MCP / Copilot` помечен как `[dev]`). Прямое подключение к работающему окну будет доступно в следующих фазах развития проекта.

## 8. Дизайн-система, надежность и локализация

* **Гарантия «Never Crash» (100% Safe Rust):**
  * Полный отказ от `unsafe`, `panic!`, `unwrap()` и `expect()`. Любые некорректные пользовательские вводы, сингулярные матрицы, пустые выборки или деление на ноль возвращают типизированную ошибку и системные пропуски, предотвращая аварийное закрытие программы.
* **Векторный интерфейс (Vector-First UI):**
  * Полный отказ от растровых иконок и Unicode-эмодзи, гарантирующий отсутствие квадратов «тофу» (`□`) в любых дистрибутивах ОС.
  * Векторная отрисовка графических примитивов через `ui.painter()` и аппаратная растеризация SVG-иконок под системный DPI монитора.
* **Нулевой хардкод строк и мгновенная локализация:**
  * 100% строк вынесены в каталоги Fluent (`locales/ru.ftl`, `locales/en.ftl`).
  * Переключение языка интерфейса (Русский $\leftrightarrow$ Английский) на лету без перезапуска приложения.
* **Кроссплатформенность:**
  * Официальная поддержка и единая кодовая база для Windows (x64), Linux (x64) и macOS (Apple Silicon ARM64 & Intel x64).
